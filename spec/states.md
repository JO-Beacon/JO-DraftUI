# 控件状态

所有实现（Flutter、以后的 C++ 等）必须表现一致。颜色用令牌表达，不写死。

## 通用状态

| 状态 | 表现 |
|---|---|
| normal | 底色透明；文字/图标用正文色或次要色 |
| hover | 底色浮起：正文色 9%（`alphaBlend` 叠加，不是直接半透明） |
| pressed | 底色浮起：正文色 20% |
| disabled | 文字/图标用次要色 50%；不响应点击；鼠标不改手型 |
| selected | 底色用强调色 14%；文字用强调色 |

“浮起”一律指在**当前底色之上叠加**，不是把整个控件变半透明。

## 动效

| 项 | 值 |
|---|---|
| 时长 | 120ms |
| 曲线 | easeOut |
| 属性 | 只改底色和描边，不改尺寸、不改位置 |

## 边框

- 常态：1px `border` 色
- hover：1px `accent` 色（有边框的控件才变）
- 无边框控件（图标动作、文字按钮）悬停只改底色

## 焦点

暂未实现。各平台适配时，焦点环统一用 1px `accent` 描边，不加外发光。

## 分栏拖动条

- 画出 1px；hover / 拖动时 2px、`accent`
- 可抓取区域 10px
- 双击复位到默认宽度

## 菜单与弹出层

| 元素 | 表现 |
|---|---|
| 菜单标题 hover | 底色：正文色 9% |
| 菜单标题展开 | 底色：正文色 12%；文字用正文色 |
| 弹出面板 | 底色 `surface`、1px `border`、2px 圆角、零阴影 |
| 面板项 hover | 底色：正文色 9% |
| 面板项选中 | 文字用 `accent` |
| 下拉展开 | 边框用 `accent` |
